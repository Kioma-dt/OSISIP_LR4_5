# Задача об обедающих философах

## Номер варианта

Вариант 1.

## Краткое описание программы

Консольная программа на C++ моделирует задачу об обедающих философах с помощью потоков WinAPI. Каждый философ поочерёдно размышляет, захватывает две соседние вилки, ест и освобождает вилки. Каждая вилка защищена критической секцией.

Вилки захватываются в порядке возрастания их номеров, что исключает циклическое ожидание ресурсов. Захват выполняется через `TryEnterCriticalSection` с повторными попытками. По истечении времени одной попытки уже захваченные вилки освобождаются, после чего философ пробует снова. Событие WinAPI используется для общей остановки и прерывания пауз при ошибке или достижении лимита времени.

Программа выводит статистику каждого философа и общие результаты: количество завершённых приёмов пищи, число успешных захватов пары вилок, количество тайм-аутов, среднее и максимальное время ожидания, длительность запуска, производительность и число нарушений проверяемых условий владения вилками. Результаты также записываются в CSV.

## Требования к среде выполнения

- ОС Windows с поддержкой используемых функций WinAPI.
- Для сборки — компилятор `g++` для Windows с поддержкой C++17, например MinGW-w64. Команда `g++` должна быть доступна в `PATH`.
- Терминал PowerShell или командная строка Windows.
- Права на запись в каталог результатов. Родительский каталог CSV должен существовать: программа не создаёт каталоги автоматически.
- При запуске на другой машине должны быть доступны библиотеки времени выполнения, от которых зависит выбранная сборка MinGW-w64.

## Инструкции по сборке

Соберите программу:

```powershell
g++ -std=c++17 -O2 -Wall -Wextra src/main.cpp src/config.cpp src/simulation.cpp -o build/philosophers.exe
```

Исполняемый файл будет создан по пути `build\philosophers.exe`.

## Параметры запуска

Все параметры необязательны. За каждым параметром, кроме `--quiet`, должно следовать значение. Временные параметры задаются в миллисекундах.

- `--n N` — число философов и вилок. Диапазон: от 2 до 64. По умолчанию: `5`.
- `--cycles C` — число приёмов пищи для каждого философа. Диапазон: от 1 до 1 000 000. По умолчанию: `100`.
- `--eat MS` — длительность одного приёма пищи. Диапазон: от 0 до 60 000. По умолчанию: `5`.
- `--think MS` — максимальная длительность размышления. Для каждого цикла выбирается случайное целое значение от 0 до указанного значения включительно. Диапазон параметра: от 0 до 60 000. По умолчанию: `5`.
- `--wait MS` — время одной попытки захвата пары вилок. После тайм-аута попытка повторяется. Диапазон: от 1 до 600 000. По умолчанию: `1000`.
- `--limit MS` — общий лимит времени одного запуска моделирования. Диапазон: от 1 до 86 400 000. По умолчанию: `600000`.
- `--seed S` — базовое начальное значение генератора случайных чисел. Для философа с номером `i` используется `S + i`. Диапазон: от 0 до 2 147 483 647. По умолчанию: `1000`.
- `--student K` — номер студента для индивидуального эксперимента. Диапазон: от 0 до 999. Устанавливает `cycles = 100 + K * 5` и `seed = 1000 + K * 97`. Не допускается совместное использование с `--cycles` или `--seed`. По умолчанию индивидуальный режим выключен.
- `--runs R` — число последовательных повторений моделирования с выбранными параметрами. Диапазон: от 1 до 100. По умолчанию: `1`.
- `--quiet` — отключение обычных сообщений о действиях философов. Сообщения об ошибках, нарушениях условий и итоговая статистика сохраняются.
- `--csv PATH` — непустой путь к CSV-файлу результатов. По умолчанию: `data\results.csv`. Путь с пробелами следует заключать в кавычки.

Пример запуска с параметрами по умолчанию:

```powershell
build\philosophers.exe
```

Коды завершения: `0` — успешное выполнение; `1` — ошибка; `2` — достижение лимита времени. При ошибке или достижении лимита оставшиеся повторения `--runs` не выполняются.

## Порядок воспроизведения экспериментов

1. Соберите программу и подготовьте каталоги `build` и `data` по инструкции выше.
2. Выполните четыре стандартных эксперимента из корневого каталога проекта:

   ```powershell
   build\philosophers.exe --n 5 --eat 5  --runs 3 --quiet --csv data\standard.csv
   build\philosophers.exe --n 5 --eat 20 --runs 3 --quiet --csv data\standard.csv
   build\philosophers.exe --n 7 --eat 5  --runs 3 --quiet --csv data\standard.csv
   build\philosophers.exe --n 7 --eat 20 --runs 3 --quiet --csv data\standard.csv
   ```

   В стандартных экспериментах каждый философ выполняет 100 приёмов пищи, базовое значение генератора равно 1000. Первая команда сохраняет результаты в `standard.csv` в корне проекта; следующие три — в `data\standard.csv`, как указано в командах экспериментов.

3. Выполните четыре индивидуальных эксперимента для студента 1:

   ```powershell
   build\philosophers.exe --student 1 --n 5 --eat 5  --runs 3 --quiet --csv data\individual.csv
   build\philosophers.exe --student 1 --n 5 --eat 20 --runs 3 --quiet --csv data\individual.csv
   build\philosophers.exe --student 1 --n 7 --eat 5  --runs 3 --quiet --csv data\individual.csv
   build\philosophers.exe --student 1 --n 7 --eat 20 --runs 3 --quiet --csv data\individual.csv
   ```

   При `--student 1` каждый философ выполняет 105 приёмов пищи, базовое значение генератора равно 1097. Результаты всех четырёх команд сохраняются в `data\individual.csv`.

4. Проверьте результаты в консоли и CSV. Для успешного запуска ожидаются статус `COMPLETED`, значение `violations = 0` и суммарное число завершённых приёмов пищи `n * cycles`: 500 или 700 для стандартных экспериментов, 525 или 735 для индивидуальных.

Каждая команда выполняет три повторения. Всего предусмотрено 24 запуска моделирования. Неуказанные параметры во всех экспериментах сохраняют значения по умолчанию: `think = 5`, `wait = 1000`, `limit = 600000`.

CSV содержит строки `WORKER` для отдельных философов и строку `SUMMARY` для каждого повторения. Результаты дописываются в существующий файл; заголовок добавляется только в пустой файл. Для новой серии без старых результатов используйте пустые файлы или другие имена. Нумерация `run` начинается с 1 при каждом запуске исполняемого файла.

Одинаковый `seed` задаёт одинаковые последовательности псевдослучайных длительностей размышления для каждого философа, однако время ожидания и производительность могут различаться из-за планирования потоков операционной системой.
